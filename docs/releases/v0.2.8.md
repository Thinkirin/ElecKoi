# ElecKoi v0.2.8

本版本为 Windows 预发布版本。

## 请求预览与更新通知

- 输入菜单新增“请求上下文预览”，可按轮次、请求查看本次运行实际发送的系统提示、设定、聊天输入和工具结果；退出后不恢复历史预览。
- 减少模型请求在聊天日志与投影缓存中的重复正文写入；聊天列表通过轻量摘要读取，避免逐条加载完整历史。
- 更新通知采用独立滚动的说明区域，完整保留长更新内容；标题、下载入口、下载进度与更新操作始终可见。

## 聊天与旧数据修复

- 修复部分旧聊天升级时缺少首条系统消息而转换失败的问题；保留原始日志，单个聊天恢复失败不再阻止客户端启动。
- 重新生成和编辑后生成保留原用户消息与同一聊天记录，减少历史消息消失、重复显示和流式结束闪烁。
- 修复中断生成、完成重新生成时的运行错误，以及下一轮开始后旧中断楼层被误标为运行中、排序错位或短暂消失。
- 修正聊天轮次、生成步数和轨迹统计，重新生成同一输入不再增加聊天轮次。
- 聊天开始后统一限制开场白切换和编辑，鼠标与键盘操作保持一致。
- 使用官方聊天视图处理滚动、历史分页和阅读位置，运行状态固定显示在输入框上方。

## 开场白、变量与编辑器

- 每个开场白可以绑定已有变量配置版本，新聊天加载对应的完整配置；已有聊天保留所用版本，角色传输和聊天存档保留绑定关系。
- 设定库、分支设定、变量和正则共用可调整宽度的侧栏与出入场动画。
- 修复新建变量版本失败的问题；版本管理提供“复制当前版本”和“创建空白版本”，复制外层下拉框选中的版本，不再自动叠加“副本”名称。
- 调整窗口大小、打开或关闭管理弹窗时，编辑栏保持挂载与编辑状态，避免重复入场。
- 统一目录条目宽度和管理图标，整理注释与关键词开关布局，移除编辑页的目录预览。

## 插件与运行环境

- 角色聊天页可显示第三方注册的会话视图，并保留同一会话的切换状态与插件生命周期。
- 插件可参与生成前准备、保存后收尾和消息回退；下一轮会等待当前操作完成保存与收尾。
- 完善 Host、Client、Remote 的公开类型和接口文档，并接入官方接口查询入口。
- 按桌面壳、桌面 Host 和 Web Client 整理工作区，保持应用身份和已有用户数据。
- 修复 Windows 更新目录解析，核对安装包中的应用许可与第三方声明。

## 下载

Windows x64 用户下载本发行版附件中的 `ElecKoi-0.2.8-x64-setup.exe` 安装包。源码压缩包不是安装程序。
